## Checklist de Publicação

Para cada artigo:
- [ ] Mínimo 1.200 palavras
- [ ] Parágrafos de no máximo 2 linhas
- [ ] 3 imagens no formato 1200x628px
- [ ] Atribuição de fonte nas imagens
- [ ] 1 link externo de autoridade
- [ ] 1 link interno para outro artigo
- [ ] FAQ com 3-4 perguntas
- [ ] Conclusão com convite ao comentário
- [ ] Indexação forçada no Search Console
- [ ] Divulgação no Facebook e Pinterest

## Páginas Obrigatórias

Antes de solicitar AdSense, criar:

1. **Quem Somos** - História do blog e propósito
2. **Política de Privacidade** - Uso de dados
3. **Termos de Uso** - Condições do conteúdo
4. **Política de Cookies** - Rastreadores
5. **Fale Conosco** - Formulário + WhatsApp
